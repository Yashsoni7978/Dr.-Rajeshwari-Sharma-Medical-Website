# Dr. Rajeshwari Sharma — Senior Consultant Physician Website

A comprehensive, content-rich, single-doctor medical practice web application for **Dr. Rajeshwari Sharma, Senior Consultant Physician (Internal Medicine)** in Jaipur, Rajasthan, India.

Built as **Project #5 of 7** in the demo portfolio of **Siyara Innovations** (Jaipur, India) to showcase high-trust medical practice Web application design with classic WordPress medical theme richness combined with Next.js 15 performance and server-rendered architecture.

---

## 🎨 Brand Identity & Design System

- **Primary Color**: `#2E4C6D` (Slate Blue — Headings, navbar, primary CTAs)
- **Canvas Background**: `#FAF8F3` (Ivory — Warm clinical canvas)
- **Accent Highlight**: `#C9A227` (Gold — Badges, star ratings, CTA accents)
- **Trust Green**: `#3E7C59` (Trust indicators, status badges, verification checkmarks)
- **Headings Font**: `Poppins` (Google Fonts via `next/font/google`)
- **Body / UI Font**: `Source Sans 3` (Google Fonts via `next/font/google`)
- **Visual Approach**: Custom illustrated "photo cards" featuring vector artwork, gradient canvases, and gold framing, replacing stock photography for zero copyright risk while maintaining a rich, photo-heavy WordPress medical aesthetic.

---

## 🚀 Technical Features & Quality Standards

- **Next.js 15 (App Router)** & **TypeScript**
- **Tailwind CSS** with custom design tokens
- **Lucide Icons** & **Framer Motion** transitions
- **100% Server-Rendered Content**: All primary content, condition listings, FAQs, specializations, and testimonials are rendered directly into server HTML for SEO crawlability and instant accessibility.
- **Full Responsiveness**: Custom top utility bar, sticky navbar, mobile navigation drawer, interactive search & filter UI, and booking lead intake funnel.

## 📋 Comprehensive 19-Section Layout

1. **Top Utility Bar & Navigation Header**: Working hours, phone helpline, location badge, and mobile drawer.
2. **Split Hero & 4-Stat Trust Strip**: Primary headline, illustrated doctor photo-card, and 4-stat clinical trust bar (18+ Yrs, 25k+ Patients, 4.9/5 Rating, MD/FICP/FACP).
3. **About Dr. Sharma**: Comprehensive physician bio, consultation philosophy card, 4 care pillars, interactive medical education stepper (SMS Medical College, AIIMS/RSSDI Fellowship), and board certifications.
4. **Specializations & Services**: 6 detailed clinical cards (Diabetes, Hypertension, Thyroid, Executive Checkups, Geriatric Care, Post-COVID Recovery).
5. **Conditions Treated**: Granular index of 30+ medical conditions across 5 categories with real-time search & filter (100% server-rendered HTML).
6. **Why Choose This Practice**: 6 practice differentiators and a side-by-side comparison matrix vs rushed hospital OPDs.
7. **Clinic Facilities / Gallery**: 4 illustrated facility cards (Consultation Chamber, Reception Lounge, Diagnostic Suite, Sample Station) & safety/hygiene panel.
8. **How It Works**: 4-step patient journey stepper (Book Slot → SMS Confirmation → Consultation → Digital Care Plan).
9. **Patient Testimonials**: 6 realistic Jaipur patient stories with condition tags, clinical outcomes, and aggregate 4.9/5 rating stats.
10. **FAQ**: 8 semantic `<details>` server-rendered accordion items covering insurance, walk-ins, duration, telehealth, ECG/labs, and wheelchair accessibility.
11. **Insurance & Hospital Affiliations**: 8 accepted insurance TPAs (Star Health, Max Bupa, ICICI Lombard, etc.) + 5 empaneled Jaipur hospital panels (Fortis, Apex, EHCC, Rungta, SMS).
12. **Meet the Care Team**: 3 supporting staff profiles (Senior Nurse Coordinator, Clinical Dietitian, Front-Desk Coordinator) with illustrated photo-cards matching the doctor's visual style.
13. **Awards & Recognition**: 6 clinical honors (API Physician of the Year, Fortis Excellence, FACP, FICP, IMA Award, RSSDI Scholar).
14. **Telehealth / Online Consultation**: 3-step virtual visit workflow, suitability matrix vs in-person visits, and transparent ₹600 pricing with PDF Rx.
15. **Community Health Initiatives**: 4 Jaipur health outreach programs (Free Diabetic Neuropathy Camps, World Hypertension Kiosks, Senior Bone Density Screening, Dengue Awareness).
16. **Consultation Fees & What to Expect**: Transparent pricing cards (₹800 First Visit, ₹500 Follow-Up, ₹600 Telehealth) & 5-point "What to Bring" patient checklist.
17. **Accessibility & Clinic Info**: Wheelchair accessibility, free reserved parking, multilingual consultations (Hindi, English, Rajasthani), and public transport/landmark guide.
18. **Health Tips / Blog Teaser**: 4 sample medical articles with read times, doctor excerpts, and monthly health newsletter subscription form.
19. **Book Appointment Funnel**: Interactive intake form (Name, Phone, Visit Mode, Date/Time pills, Primary Concern) with instant Booking Reference ID generation.
20. **Location & Contact**: Malviya Nagar address, operating hours table, map placeholder graphic with Google Maps link, and direct inquiry form.
21. **Footer**: 4-column sitemap, medical credentials, emergency medical disclaimer, copyright, and Siyara Innovations portfolio credit.

## 🛠️ Local Development & Build Setup

### Prerequisites
- Node.js 18.x or 20.x installed

### Quick Start
```bash
# Clone the repository
git clone https://github.com/siyarainnovations/dr-rajeshwari-sharma.git

# Navigate to project directory
cd "dr rajeshwari"

# Install dependencies
npm install

# Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 📦 Production Build & Deploy

```bash
# Verify TypeScript type correctness
npx tsc --noEmit

# Build production bundle
npm run build

# Start production server
npm run start
```

Ready for seamless 1-click deployment on **Vercel** or **Netlify**.
